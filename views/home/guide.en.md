# Home {#top}

The landing page of the plugin. For now it only shows a welcome message: **Welcome**, and a line saying that this is the plugin's landing page. It reads and writes nothing.

From here, use the tabs above to reach the tools of the plugin:

- [Worktable Explorer](guide:worktable-explorer): look at and correct the raw data of any table;
- [Endpoints](guide:endpoints): the addresses to connect this instance to other programs and to AI assistants;
- [MCP Checker](guide:mcp-checker): test an MCP endpoint and list its tools;
- [Tools](guide:tools): download the Python helper scripts;
- [Configuration](guide:config): change the name of the data directory;
- *Help*: the manual you are reading.
