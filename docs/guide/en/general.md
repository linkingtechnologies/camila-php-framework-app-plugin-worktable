# Worktable — user guide {#top}

The **worktable** plugin gathers the technical tools of a CAMILA WorkTable instance: looking at the raw data, connecting the instance to other programs and to AI assistants, copying data with scripts, and protecting the data directory. It is meant for administrators and developers more than for the people who work in the applications every day.

## The pages {#pages}

Each tab of the plugin is a page with its own guide:

- [Home](guide:home): the landing page;
- [Worktable Explorer](guide:worktable-explorer): look at and correct the raw data of any table;
- [Endpoints](guide:endpoints): the addresses of this instance, and how to connect Claude Desktop and ChatGPT;
- [MCP Checker](guide:mcp-checker): test an MCP server and list its tools;
- [Tools](guide:tools): download the Python helper scripts;
- [Configuration](guide:config): rename the data directory to an unguessable name.

The last tab, *Help*, opens this manual.

## How to read the guides {#reading}

- text in **bold** is a label exactly as the screen shows it: a button, a field, a message;
- *italic* is emphasis, or a name that is not a label;
- every guide is divided into short sections: use the menu on the left of the manual, or the search box (press `/` to reach it).

## Where to find the guide {#where}

- in the manual: the **Manual** button of the *Help* tab opens it in a new tab, with the menu, the search and the pages in print order;
- while you work: the round **?** button at the bottom right of every page opens the guide of that page in a side panel, without leaving it. **Full manual** in the panel opens the manual;
- the manual is available in English and in Italian; it follows the language of the application.

On a page of the manual, **Open the page ↗** opens the page described by that guide.
